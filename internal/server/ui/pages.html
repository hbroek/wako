    Markdown cheatsheet
    # Title ## Section ### Partheadings
    **bold** *italic* ~~strike~~ `code`emphasis
    [text](other-page) [text](https://example.com)links (a bare https://… is linked too)
    [[Page name]] [[Page name|label]]shortcut: becomes a link when you save, and creates the page if it is new
    [manual](manual.pdf)a link to a PDF in the library (Image / PDF… button)
    ![alt](picture.png) ![alt](picture.png?w=400) ?h=300an image from the library (Image… button), optionally this many pixels wide or high (60 for a thumbnail, 240, 400, 600, 800, 1200, 1600)
    - item 1. item (indent two spaces to nest)bulleted and numbered lists
    - [ ] to do - [x] donetask list, shown as ⬜ and ✅
    > quotequotation
    ``` on its own line before and aftercode block
    | a | b | then |---|---| then | 1 | 2 |table (:---: centres a column)
    ---horizontal rule

    Raw HTML and footnotes are not shown. Ctrl+B / Ctrl+I bold and italicise the selection; Ctrl+Alt+1–3 make a heading.

    Images and PDFs

    Choosing a PDF inserts a link, [name](name.pdf). Choosing an image inserts ![alt](name), or ![alt](name?w=400) with a size. The server makes the smaller picture when it is first asked for, and keeps it. The page keeps a link to the image by name.
